# Cooling Pad Controller

A Python project for monitoring laptop temperatures and developing an intelligent cooling pad controller.

## Planned Features

- CPU temperature monitoring
- Automatic fan speed control
- Manual fan control
- Individual control for three fans
- Temperature and fan-speed graphs
- GUI built with PySide6
- Hardware monitoring integration with LibreHardwareMonitor

## Technologies

- Python
- PySide6
- pyqtgraph
- LibreHardwareMonitor

## Project Status

Under development.

Features listed above are planned or under development and may not all be implemented yet.
